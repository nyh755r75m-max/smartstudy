# smartstudy

Starter‑Projekt: Web‑Lernapp (Next.js + TypeScript + Tailwind). Enthält:
- To‑Do / Lernplan
- Karteikarten
- Lern‑Timer
- Taschenrechner
- Hintergrund‑Geräusche (On/Off + Lautstärke)
- Theme/Farbwechsel
- Mock‑KI Chat (lokal)

Schnellstart:
1. npm install
2. npm run dev
3. Öffne http://localhost:3000

Zum Hochladen: ZIP erstellen und über GitHub → New repository → Add file → Upload files hochladen.
